## About / 关于

**HachimiWorld** is a community-driven open-source meme culture music community.

**基米天堂**是一个由社区驱动的开源梗文化音乐社区。

This repository is the **client application**, built with Kotlin Multiplatform + Compose Multiplatform, targeting Android, iOS, Desktop, and Web.

此仓库为**客户端应用**，使用 Kotlin Multiplatform + Compose Multiplatform 构建，覆盖 Android、iOS、Desktop 和 Web 平台。

The backend is also open source, and the source code is available at 

后端同样开源，源代码在此仓库：

[HachimiWorld/hachimi-world-server](https://github.com/HachimiWorld/hachimi-world-server)
