## Features 功能

1. Support random/repeat playback. 支持随机/重复播放模式
2. Show MV links. 显示 MV 链接
3. Support removing song from playlist. 支持从歌单中移出歌曲

2. Fixed some issues in lyrics. 修复滚动歌词的部分问题

## Improvements 改进
