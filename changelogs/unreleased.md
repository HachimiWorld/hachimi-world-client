## Features 新功能

1. Added the Square, where you can browse and post moments with images, a song or a playlist. 新增广场，可浏览和发布动态，动态可附带图片、歌曲或歌单。
2. Moments can be liked, commented on and reported. 动态支持点赞、评论与举报。
3. Added a Moments tab to user pages. 个人主页新增「动态」栏目。
4. Announcements now live in the Square. 公告移至广场。

## Fixes 修复

1. The comment box now uses the app's font, and its text is vertically centered. 评论输入框改用应用字体，文字垂直居中。
